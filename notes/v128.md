**Isekai Village v128**: In-game updates 🔄

🔄 **Update from inside the game**: the Windows and Android apps now tell you when a new version is out (a small ✨ note on the title screen) and update themselves with one tap, from the title screen or **Settings → Town & Save → Game updates**. Every download is checked against the checksums below before it's used.

🪟 **Windows**: the installed game downloads the new version, closes, updates and opens again by itself. The portable exe puts the new one next to itself and starts it. Your towns stay where they are, and the old save is backed up first.

🤖 **Android**: the app downloads the new APK and opens Android's installer: tap **Update**. The first time, Android asks you to allow installs from Isekai Village. Your towns stay safe.

📌 **This one is a manual update** (v127 doesn't have the button yet). From v128 on, updating happens in the game.

🍎 **New: Mac and 📱 iPhone/iPad.** The same game for Apple devices: `IsekaiVillage-v128-mac.zip` for Macs (Apple silicon and Intel) and `IsekaiVillage-v128-ios.ipa` for iPhone and iPad, installed with AltStore or Sideloadly. They don't update themselves yet: download each new version from this page. Install help: see the [README](https://github.com/KatoGrey/isekai-village-downloads#readme).

**Which file?** Windows: `IsekaiVillage-Setup-v128.exe` (installer) or `IsekaiVillage-v128.exe` (portable). Android: `IsekaiVillage-v128.apk`. Mac: `IsekaiVillage-v128-mac.zip`. iPhone and iPad: `IsekaiVillage-v128-ios.ipa`. Install help: see the [README](https://github.com/KatoGrey/isekai-village-downloads#readme).
