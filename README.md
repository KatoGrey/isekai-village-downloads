# 🏡 Isekai Village — Downloads

A cozy pixel isekai town builder. Summon heroes, grow a village into a kingdom, and explore the Vast Frontier.

## ⬇️ Get the game
**[Download the latest version here](https://github.com/KatoGrey/isekai-village-downloads/releases/latest)** and pick the file for your device, under **Assets**:

| Device | File | What it is |
|---|---|---|
| Windows (recommended) | `IsekaiVillage-Setup-vXXX.exe` | Installs the game, with Desktop and Start Menu shortcuts |
| Windows (no install) | `IsekaiVillage-vXXX.exe` | A single file you just run |
| Android | `IsekaiVillage-vXXX.apk` | The phone/tablet app, full screen (great on foldables) |

## 🪟 Windows
1. Download the **Setup** file (or the portable one) and open it.
2. If Windows shows **"Windows protected your PC"**, click **More info → Run anyway**. The game isn't from the Microsoft Store, so Windows doesn't recognise it yet.
3. Play! The Setup version adds a shortcut; the portable one runs right away.

## 🤖 Android
1. Download the **.apk** on your phone and open it.
2. If asked, allow installs from your browser or Files app (**Settings → allow from this source**), then go back and tap **Install**.
3. If Play Protect warns about an unknown app, tap **Install anyway** (it isn't from the Play Store).

## 🔄 Updating
**From v128 on, the apps update themselves:** a small ✨ note on the title screen says when a new version is out, and one tap updates (or use **Settings → Town & Save → Game updates**). On Android, tap **Update** when Android asks; the first time, allow installs from Isekai Village.

On an older version? Just download and run/install the new version. **Your towns carry over automatically**. On Windows, the old save is also backed up first, to `%APPDATA%\Isekai Village\save-backups`.

Moving a town to another device? In the game, use **Settings → Town & Save → 💾 Save to a file**, then on the other device: **🏘 Towns & Saves → 📂 Bring Save File Over**.
