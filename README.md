# 🏡 Isekai Village — Downloads

A cozy pixel isekai town builder. Summon heroes, grow a village into a kingdom, and explore the Vast Frontier.

## ⬇️ Get the game
**[Download the latest version here](https://github.com/KatoGrey/isekai-village-downloads/releases/latest)** and pick the file for your device, under **Assets**:

| Device | File | What it is |
|---|---|---|
| Windows (recommended) | `IsekaiVillage-Setup-vXXX.exe` | Installs the game, with Desktop and Start Menu shortcuts |
| Windows (no install) | `IsekaiVillage-vXXX.exe` | A single file you just run |
| Android | `IsekaiVillage-vXXX.apk` | The phone/tablet app, full screen (great on foldables) |
| Mac | `IsekaiVillage-vXXX-mac.zip` | The Mac app (Apple silicon and Intel) |
| iPhone / iPad | `IsekaiVillage-vXXX-ios.ipa` | The iPhone and iPad app, installed with a free tool (see below) |

## 🪟 Windows
1. Download the **Setup** file (or the portable one) and open it.
2. If Windows shows **"Windows protected your PC"**, click **More info → Run anyway**. The game isn't from the Microsoft Store, so Windows doesn't recognise it yet.
3. Play! The Setup version adds a shortcut; the portable one runs right away.

## 🤖 Android
1. Download the **.apk** on your phone and open it.
2. If asked, allow installs from your browser or Files app (**Settings → allow from this source**), then go back and tap **Install**.
3. If Play Protect warns about an unknown app, tap **Install anyway** (it isn't from the Play Store).

## 🍎 Mac
1. Download the **-mac.zip** file and open it: it becomes **Isekai Village**. Drag it into your **Applications** folder.
2. Open it. The first time, macOS says it can't check the app: click **Done**, then go to **System Settings → Privacy & Security**, scroll down and click **Open Anyway** next to Isekai Village (you may need your password). The game isn't from the App Store, so Apple doesn't know it yet. You only do this once.
3. Play! Your towns are kept in your Mac's user folder (`~/Library/Application Support/Isekai Village`).

## 📱 iPhone and iPad
Apple only lets App Store apps install with one tap, so the iPhone app goes on with a free helper on your computer, signed with your own Apple ID:
1. On your Windows PC or Mac, install **[AltStore](https://altstore.io)** (it keeps the app fresh by itself) or **[Sideloadly](https://sideloadly.io)**.
2. Download the **-ios.ipa** file, connect your iPhone or iPad, and give the file to AltStore or Sideloadly. Sign in with your Apple ID when it asks.
3. On the iPhone: if asked, turn on **Settings → Privacy & Security → Developer Mode**, and trust your Apple ID under **Settings → General → VPN & Device Management**.
4. With a free Apple ID the app has to be refreshed every **7 days**. AltStore does it on its own when your phone and computer share Wi-Fi; with Sideloadly, just install it again. Your towns stay in between, but a **💾 Save to a file** now and then is a good idea.

## 🔄 Updating
**From v128 on, the apps update themselves:** a small ✨ note on the title screen says when a new version is out, and one tap updates (or use **Settings → Town & Save → Game updates**). On Android, tap **Update** when Android asks; the first time, allow installs from Isekai Village.

On an older version? Just download and run/install the new version. **Your towns carry over automatically**. On Windows, the old save is also backed up first, to `%APPDATA%\Isekai Village\save-backups` (on a Mac, to `save-backups` in the folder above).

**Mac and iPhone/iPad** don't update themselves yet: when a new version is out, download it here and open it (Mac) or install it over the old one (iPhone, with the same tool and Apple ID). Your towns stay.

Moving a town to another device? In the game, use **Settings → Town & Save → 💾 Save to a file**, then on the other device: **🏘 Towns & Saves → 📂 Bring Save File Over**.
